macOS 同应用不同窗口切换，原作者 [DevSwitcher2](https://github.com/vaspike/DevSwitcher2)，在原来代码的基础上做了精简，**只解决“同应用不同窗口”的切换问题**。没有浮动窗口没有复杂设置！



### 系统要求
- macOS 12.0 或更高版本
- 辅助功能权限（首次运行时会自动引导设置）
